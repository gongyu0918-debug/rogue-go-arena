rogue-go-arena は Windows 用の囲碁ゲームです。本物の碁盤で、トップクラスの囲碁エンジン KataGo と対局します。

対局の前にカードを1枚選びます。カードはルールを少しだけ変えます。石を取るたびに石が1つ生えるカードや、AI の着手点を指定できるカードなどがあります。毎局ちがう展開になりますが、中身は囲碁なので、良い手はきちんと勝ちにつながります。

## ダウンロードと始め方

1. [最新リリース](https://github.com/gongyu0918-debug/rogue-go-arena/releases/latest) を開きます。
2. `rogue-go-arena_WebView_Setup_<バージョン>.exe` をダウンロードして実行します。ユーザー単位のインストールなので管理者権限は不要です。
3. デスクトップかスタートメニューから起動します。

Windows 10 または 11（64 ビット）が必要です。GPU があると速くなりますが、なくても CPU で動きます。表示言語は英語、簡体中国語、繁体中国語、日本語、韓国語、フランス語、ドイツ語から選べます。

## モード

- **対局**：通常の AI 対局。難易度に応じて置き石がつきます。「上級者向け」にチェックすると棋力・置き石・コミを自分で決められます。
- **Rogue**：19路のカード対局。「クイックゲーム」はあなただけがカードを持ち、「デュアルドラフト」では AI もカードを持ちます。
- **チャレンジ**：5局の連戦。あなたは白番で、ステージごとにカードを1枚追加します。AI のコミはステージごとに増え、第3ステージからは置き石つきで始まります。
- **研究**：AI 同士の対局を観戦します。
- **二人**：1台のパソコンで2人が対局します。

カードは1行の説明つきで、「遊び方」から詳しいルールを見られます。カードが強いほど AI にコミが加わります。画面上部に「目標」（AI の先行分）と現在のリードが表示され、目標を上回れば勝ちです。

## よくある質問

- **難易度は？** まずは「入門」か「かんたん」から。AI の強さは一定で、難易度はあなたへの助けの量を決めます。
- **カードは変更できる？** できます。「設定」からカード編集を開いてください。次の対局から反映されます。
- **Windows がインストーラーを警告する？** コード署名がないため SmartScreen が表示されることがあります。上のリリースページから入手したものなら「詳細情報」→「実行」で進めます。
