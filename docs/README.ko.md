rogue-go-arena는 Windows용 바둑 게임입니다. 진짜 바둑판에서 최강급 바둑 엔진인 KataGo와 대국합니다.

대국 전에 카드를 한 장 고릅니다. 카드는 규칙을 조금 바꿉니다. 돌을 따낼 때마다 돌이 하나 자라나는 카드도 있고, AI가 둘 곳을 정해 주는 카드도 있습니다. 매 판이 다르게 흘러가지만 결국 바둑이라서 좋은 수가 이깁니다.

## 다운로드와 시작

1. [최신 릴리스](https://github.com/gongyu0918-debug/rogue-go-arena/releases/latest)를 엽니다.
2. `rogue-go-arena_WebView_Setup_<버전>.exe`를 내려받아 실행합니다. 현재 사용자에게만 설치되므로 관리자 권한이 필요 없습니다.
3. 바탕화면이나 시작 메뉴에서 실행합니다.

Windows 10 또는 11(64비트)이 필요합니다. 그래픽카드가 있으면 더 빠르지만 없어도 CPU로 돌아갑니다. 영어, 중국어 간체·번체, 일본어, 한국어, 프랑스어, 독일어를 지원합니다.

## 모드

- **대국**: 일반 AI 대국입니다. 난이도에 따라 접바둑 돌을 받습니다. '고급'을 체크하면 기력, 접바둑, 덤을 직접 정할 수 있습니다.
- **Rogue**: 19줄 카드 대국입니다. '빠른 대국'은 나만 카드를 갖고, '듀얼 드래프트'는 AI도 카드를 받습니다.
- **도전**: 5판 연전입니다. 나는 백으로 두고 단계마다 카드를 한 장 더 고릅니다. AI의 덤은 단계마다 늘고, 3단계부터는 접바둑 돌을 놓고 시작합니다.
- **학습**: AI끼리 두는 대국을 봅니다.
- **2인**: 한 컴퓨터에서 두 사람이 둡니다.

카드마다 한 줄 설명이 있고, '자세히 보기'에서 전체 규칙을 볼 수 있습니다. 카드가 강할수록 AI가 덤을 더 받습니다. 화면 위에 '목표'(AI가 앞서 시작하는 만큼)와 현재 내 리드가 표시되며, 목표를 넘으면 이깁니다.

## 자주 묻는 질문

- **난이도는?** '입문'이나 '쉬움'부터 시작하세요. AI 실력은 고정이고, 난이도는 내가 받는 도움의 양을 정합니다.
- **카드를 바꿀 수 있나요?** 네. '설정'에서 카드 편집기를 여세요. 다음 대국부터 적용됩니다.
- **Windows가 설치 파일을 경고해요.** 코드 서명이 없어서 SmartScreen이 뜰 수 있습니다. 위 릴리스 페이지에서 받은 파일이라면 '추가 정보' → '실행'을 누르세요.
